## TryHackMe - Pre Security: Operating Systems Introduction
### Room Summary
An introductory room in the Pre Security path covering the basics of operating systems and their core function in managing a computer's resources.

### Key Takeaways
- The operating system acts as an "invisible manager" that handles the device's resources (CPU, RAM, storage) without the user interacting with it directly
- Differences between common operating systems (Windows, macOS, Linux) and how each interacts with the user
- How RAM is managed and allocated across multiple programs running at the same time
- One thing that clicked for me in this room was the difference between GUI and CLI. I'd always used a GUI without thinking about it, but understanding that the CLI gives more direct control over the system helped me see why it's so important in cybersecurity

### Why This Matters for Cybersecurity
Understanding how an operating system manages resources and permissions is the foundation for understanding how security vulnerabilities occur later on (such as privilege escalation) — knowing how the system works internally helps identify where weaknesses can arise.
